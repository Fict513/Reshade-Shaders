# Primary sources and inspection record

Research and validation performed 2026-11-04. Sources describe mechanisms; they do not establish the encoding of an unspecified game.

1. **ReShade FX reference**, official repository: [REFERENCE.md](https://github.com/crosire/reshade-shaders/blob/slim/REFERENCE.md). Defines COLOR semantics, source textures, point samplers, SRGBTexture, pass targets and SRGBWriteEnable. The shader sets the relevant states explicitly.
2. **ReShade runtime**, inspected checkout commit `7bf9de8b33bcc76c3177007e65d73c72dd0f34c0`:
   - [runtime.cpp, add_effect_permutation](https://github.com/crosire/reshade/blob/7bf9de8b33bcc76c3177007e65d73c72dd0f34c0/source/runtime.cpp#L3590): raw color format normalization; same-format COLOR resource and two views.
   - [runtime.cpp, sampler binding](https://github.com/crosire/reshade/blob/7bf9de8b33bcc76c3177007e65d73c72dd0f34c0/source/runtime.cpp#L2762): COLOR's raw/sRGB SRV chosen from sampler state.
   - [runtime.cpp, render_technique](https://github.com/crosire/reshade/blob/7bf9de8b33bcc76c3177007e65d73c72dd0f34c0/source/runtime.cpp#L4118): prior back-buffer copy; [target selection](https://github.com/crosire/reshade/blob/7bf9de8b33bcc76c3177007e65d73c72dd0f34c0/source/runtime.cpp#L4190).
   - [runtime.cpp, image loading](https://github.com/crosire/reshade/blob/7bf9de8b33bcc76c3177007e65d73c72dd0f34c0/source/runtime.cpp#L3053): PNG loading, error reporting and component collapse. [R8 creation](https://github.com/crosire/reshade/blob/7bf9de8b33bcc76c3177007e65d73c72dd0f34c0/source/runtime.cpp#L3145) and upload code were inspected.
   - [effect compiler sources](https://github.com/crosire/reshade/tree/7bf9de8b33bcc76c3177007e65d73c72dd0f34c0/source): actual preprocessor/parser/HLSL/GLSL generators built for validation. One lexer float-parser portability substitution is disclosed in TESTING.md.
3. **Microsoft**, [Use DirectX with Advanced Color](https://learn.microsoft.com/en-us/windows/win32/direct3darticles/high-dynamic-range). Documents FP16/scRGB composition, extended signed range, 80-nit nominal white and HDR application output choices. The package does not assume an application's buffer matches presentation metadata or output settings.
4. **Microsoft**, [DXGI_COLOR_SPACE_TYPE](https://learn.microsoft.com/en-us/windows/win32/api/dxgicommon/ne-dxgicommon-dxgi_color_space_type). Defines full-range G22/P709, linear G10/P709 and G2084/P2020 contracts; explains that G22/P709 is intended as piecewise sRGB. These are interpretation contracts, not measurements of image content.
5. **Microsoft**, [Direct3D 11.3 functional specification §3.2.3.6](https://microsoft.github.io/DirectX-Specs/d3d/archive/D3D11_3_FunctionalSpec.htm#FLOATtoUNORM). Defines ideal FLOAT→UNORM conversion and permits 0.6 ULP on the integer side. This explains why ideal nearest-code arithmetic is not a sufficient hardware prediction. The observed driver bias is measured separately; no exact hardware conversion algorithm is inferred.
6. **Robert Ulichney (1993)**, [The void-and-cluster method for dither array generation, author's paper](https://cv.ulichney.com/papers/1993-void-cluster.pdf). Basis for the toroidal cluster/void ranking method implemented independently here. Scalar and threshold spectra are measured, rather than assuming every generated mask is adequate.
7. **Lipshitz, Wannamaker and Vanderkooy (1992)**, [Quantization and Dither: A Theoretical Survey, AES](https://aes.org/publications/elibrary-page/?id=7047). Provides the distinction between quantization error, nonsubtractive dither and statistical conditions. The shader uses nonsubtractive finite uniform spatial dither; it does not claim independent total error or signal-independent variance. Numerical derivations and results in this package are our own.
8. **Christoph Peters**, [Free blue noise textures](https://momentsingraphics.de/BlueNoise.html). Primary practical discussion of scalar masks, threshold distributions and tiling. Its downloadable assets/code were **not** used in this package; there is no third-party texture dependency.

The actual installed game, Signal Inspector source, HDR composition path, monitor behavior and driver output dither were not inspected. No claims about those are inferred from these sources.
